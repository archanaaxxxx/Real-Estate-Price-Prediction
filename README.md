# 🏡 Real Estate Price Prediction and Interactive Map

## 📌 Project Overview

This project predicts real estate property prices using Machine Learning and visualizes property locations on an interactive map. It demonstrates the complete data analysis workflow, including data preprocessing, visualization, model training, evaluation, and geospatial mapping.

The project was developed using **Python** in **Google Colab** and is suitable for beginners learning Data Science and Machine Learning.

---

## 🚀 Features

* Import and analyze real estate data
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Property distribution visualizations
* Correlation heatmap
* Interactive property map using Folium
* House price prediction using Linear Regression
* Model performance evaluation using R² Score and Mean Absolute Error (MAE)

---

4. Run all cells in sequence.
5. View the generated charts and interactive map.
6. Evaluate the machine learning model.
