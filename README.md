# 🏠 Real Estate Market Analysis using Machine Learning

## 📌 Project Overview

This project analyzes a multivariate real estate dataset to predict property prices and identify different housing market segments. It combines **Machine Learning**, **Data Analysis**, **Clustering**, and **Interactive Mapping** to support data-driven real estate and business decisions.

The project demonstrates how property features such as area, bedrooms, bathrooms, parking, and property type influence house prices. It also groups similar properties into market segments using clustering techniques and visualizes them on an interactive map.

---

## 🎯 Objectives

* Predict house prices using Machine Learning.
* Analyze relationships between property features and price.
* Segment the housing market into different clusters.
* Visualize property locations using an interactive map.
* Generate insights for real estate market analysis and expansion planning.

---

## 📂 Dataset

The dataset contains the following features:

* Property_ID

* Longitude
* Area_sqft
* Bedrooms

* Age
* Parking
